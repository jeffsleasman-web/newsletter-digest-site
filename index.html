Newsletter Digest

A personal tool for summarizing email newsletters.

What it does

Newsletter Digest is a small script that reads email newsletters from a single Gmail account, produces a written summary of them, and files the originals away. It exists because its author subscribes to more newsletters than he can read, and would rather have one weekly summary than an inbox of unread mail.

Who it is for

One person. This is a personal project running on a personal laptop against a single mailbox. It is not a product, it is not offered as a service, and it has no users other than its author.

How it works

The script connects to Gmail using Google's official API, with permission granted by the account holder. It reads messages under a single label, sends their text to Anthropic's Claude API to be summarized, writes the summary to a file on the author's computer, and marks the original messages as read and archived. It cannot permanently delete email.
