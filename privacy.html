Privacy Policy

Newsletter Digest · Last updated September 11, 2026

Summary

Newsletter Digest is a personal script with one user: its author. It reads that person's own email newsletters and summarizes them. It has no other users, it collects nothing from anyone else, and it sells nothing to anyone.

What the application accesses

With permission granted through Google's standard consent process, the application requests a single Gmail permission: https://www.googleapis.com/auth/gmail.modify. This allows it to:

  • Read messages in the account, including subject lines and message bodies
  • Mark messages as read
  • Apply and remove labels, which is how messages are archived

This permission does not allow permanent deletion of email. It does not grant access to Google Drive, Calendar, Contacts, or any other Google service.

In practice the application only reads messages under one Gmail label, which contains email newsletters from publishers. It does not read personal correspondence.

What happens to the data

  • Newsletter text is sent to Anthropic's Claude API to be summarized. This is the only third party involved. Anthropic's handling of API data is governed by its own published policies.
  • Summaries are written to a file on the author's computer. They are not uploaded anywhere, published, or shared.
  • Message contents are not stored beyond what appears in the summary. The application does not keep a copy of the emails it reads.

What is not done with the data

  • It is not sold, rented, or licensed to anyone.
  • It is not used for advertising or profiling.
  • It is not shared with any third party other than the summarization API described above.
  • It is not used to train any machine learning model by the author.

Credentials

Google authorization is stored as a token file on the author's own computer. It is excluded from version control and is not uploaded to any repository or cloud storage service. Access can be revoked at any time from the Google Account permissions page, which immediately ends the application's access.

Data retention

Summaries remain on the author's computer until deleted by the author. No data is retained anywhere else by this application.

Children

This application is not directed at children and has no users other than its author.

Changes

If what the application does changes, this page will be updated and the date at the top revised.
